# spm

Smart Project Manager — a CLI tool to manage multiple projects, scaffold new ones, and keep your dev environment consistent.

## Install

```sh
go install github.com/alexmatiasas/spm/cmd/spm@latest
```

## Usage

```sh
# Show version
spm version

# More commands coming soon
```

## Development

```sh
# Build
make build

# Run tests
make test

# Lint
make lint

# Format
make format
```
