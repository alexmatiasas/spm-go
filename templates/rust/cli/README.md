# {{PROJECT_NAME}}

Command line tool scaffolded by spm.

## Setup

Requires rustup. Build and test with cargo:

```bash
cargo build
cargo test
```

## Usage

```bash
just run       # cargo run
just lint      # clippy, warnings as errors
just fmt       # rustfmt
```

Run `just --list` to see every available task.

